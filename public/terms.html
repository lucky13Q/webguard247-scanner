2. What the service is

WebGuard247 runs a passive security scan of a website address you enter. It only looks at what any ordinary web browser can see: the TLS certificate, HTTP response headers, cookies, DNS and email-authentication records and publicly served content. It then reports the issues it finds, graded red, amber and green, with a score.

The scanner never attempts to log in, guess passwords, probe for hidden pages, exploit vulnerabilities, send unusual traffic or interact with any part of a site that is not publicly served. It is not a penetration test.
